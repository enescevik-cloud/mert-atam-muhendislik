# Mert Atam Mühendislik Web Projesi

## Çalıştırma
```powershell
npm install
npm run dev
```

## Fotoğraf klasörleri
Görselleri `src/assets/` altında ilgili klasörlere ekleyin.

- `src/assets/logo/`
- `src/assets/hero/`
- `src/assets/about/biz-kimiz/`
- `src/assets/about/vizyon/`
- `src/assets/about/misyon/`
- `src/assets/services/...`
- `src/assets/partners/`

## Not
Proje fotoğrafsız skeleton olarak hazırlanmıştır. Görseller eklendiğinde componentlerdeki placeholder alanlar gerçek görsellerle değiştirilebilir.
